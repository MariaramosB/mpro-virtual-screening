# Previous Academic Work

## Structural and Computational Analysis of SARS-CoV-2 Mpro

This project builds on previous academic work focused on the SARS-CoV-2 main protease (Mpro/3CLpro) and the experimentally determined structure PDB 7BQY.

The previous study characterized the structure of Mpro in complex with the covalent inhibitor N3 and examined the catalytic dyad formed by His41 and Cys145.

The study included:

* structural characterization of SARS-CoV-2 Mpro;
* analysis of the Mpro active site;
* characterization of the interaction between N3 and the active site;
* molecular dynamics analysis of a Cys145→Ala mutation;
* molecular docking of a small set of compounds.

The present project uses this previous academic work as a starting point and extends it into a broader and more reproducible structure-based virtual screening workflow.

The new workflow will focus on protein preparation, docking protocol validation, screening of a publicly available compound library, molecular descriptor analysis and predicted ADME properties.

## Previous structure

**PDB:** 7BQY
**Target:** SARS-CoV-2 main protease (Mpro/3CLpro)
**Bound ligand:** N3
**Catalytic residues:** His41 and Cys145

The previous study identified interactions between N3 and several active-site residues, including Gly143, His163, Glu166 and Gln189.

## Relation to the present project

The previous work provided the structural and computational background for the present study.

While the previous project investigated a specific Mpro mutation and a limited set of docked compounds, the present project aims to develop a reproducible workflow for virtual screening and candidate prioritization.

The two projects therefore share the same biological target but have different computational objectives.
