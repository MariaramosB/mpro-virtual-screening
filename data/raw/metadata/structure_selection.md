## Initial rationale

PDB 7BQY was selected as the initial structural reference for the SARS-CoV-2 Mpro virtual screening project.

The structure contains Mpro in complex with the inhibitor N3 and provides an experimentally determined reference structure for analysis of the active site and ligand-binding region.
